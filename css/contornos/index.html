Contornos e Relevo: Borda, Outline e Sombra

Se a estilização de textos cuida da mensagem, os contornos cuidam da forma. No CSS, temos três ferramentas principais para definir os limites e a profundidade de um elemento. Entender a diferença entre elas é o que separa um layout "chapado" de uma interface moderna e profissional.

Molduras

Embora pareçam iguais, essas duas propriedades se comportam de formas completamente diferentes no espaço do seu site.

  1. Border (A Borda Real)

    A border é a moldura clássica.

    • Impacto no Espaço: Lembra do Box Model? A borda ocupa espaço. Se você adicionar uma borda de 5px em um botão, ele vai "empurrar" os elementos vizinhos para caber.
    • Sintaxe: Ela precisa de três valores: largura, estilo e cor.
    • Estilos comuns: solid (linha contínua), dashed (tracejada) e dotted (pontilhada).
    • Exemplo: border: 2px solid black;
  2. Border-radius (O Fim das Quinas)

    Antigamente, tudo na web tinha quinas de 90 graus. O border-radius mudou isso.

    • Suavização: Com ele, você arredonda os cantos. Se você tiver um quadrado de 100px e aplicar border-radius: 50%, ele vira um círculo perfeito.
    • Dica de Design: Arredondamentos leves (4px a 8px) dão um ar amigável e moderno para botões e cartões de informação.
  3. Outline (O Contorno de Destaque)

    O outline é como uma "aura" ao redor da caixa.

    • O Segredo: Ele NÃO ocupa espaço. Ele é desenhado por cima de tudo, sem empurrar ninguém.
    • Uso Principal: Acessibilidade. Sabe quando você aperta "Tab" e um retângulo azul aparece em volta de um link? Aquilo é um outline. Ele serve para mostrar onde o foco do usuário está sem quebrar o layout.
