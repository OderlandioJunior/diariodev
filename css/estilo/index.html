Cores, Fontes e a Identidade do Site

Depois de entender que tudo na internet são "caixas" (o famoso Box Model), chega a hora de aprender a personalizar essas caixas. Estilizar é o processo de definir a aparência: que cores usar, qual o tamanho das letras e como as fontes devem se parecer.

Onde as Cores e Fontes Nascem

Antes de pintar, precisamos entender os "baldes de tinta" e como trazer novas ferramentas para o nosso trabalho.

  1. Como o computador entende as cores?

    Você não precisa saber apenas os nomes das cores em inglês (como red ou blue). Existem formas mais precisas:

    • Hexadecimal (#): É um código de 6 letras e números. É o jeito mais usado no mundo. Ex: #000000 é preto, #FFFFFF é branco.
    • RGB e RGBA: Funciona como misturar tintas reais (Red/Vermelho, Green/Verde, Blue/Azul). O "A" no final é o segredo da transparência: se você quer uma cor que deixe ver o que está atrás, você mexe no "A".
  2. Trazendo fontes e arquivos de fora

    Às vezes, as fontes que já vêm no computador são sem graça. Para usar fontes bonitas (como as do Google), usamos um comando chamado @import.

    Ele funciona como um "mensageiro": você coloca ele no topo do seu código e ele vai buscar a fonte na internet para você usar. É assim que sites profissionais conseguem ter visuais únicos.

Moldando o seu Texto

O texto é a parte mais importante de um site. Se ele estiver difícil de ler, o usuário vai embora. Aqui estão os três pilares para evitar isso:

  1. Propriedades de Fonte (font-)

    Imagine que você está escolhendo uma caneta para escrever:

    • font-family: É o "estilo" da letra. Defina sua "pilha de fontes" (font-stack). Comece pela fonte personalizada e termine sempre com uma família genérica (sans-serif ou serif) para garantir o fallback do sistema.
    • font-size: É o tamanho da letra. Embora o px seja fixo, em projetos reais você começará a ver o rem. Ele é relativo ao tamanho da fonte do navegador, respeitando a preferência de zoom do usuário.
    • font-weight: Controla a espessura. Valores numéricos (de 100 a 900) oferecem mais precisão que apenas bold ou normal.
  2. Organizando o Bloco de Texto (text-)

    Aqui você ajusta como as palavras se comportam na tela:

    • text-align: Quer o texto no meio? Alinhado à esquerda? É aqui que você manda.
    • text-decoration: Essencial para o controle visual de links. O valor none remove o sublinhado padrão, permitindo que você crie interações mais modernas
    • text-transform: É uma ferramenta de consistência. Se você quer que todos os títulos sejam maiúsculos, use uppercase no CSS em vez de digitar tudo em Caps Lock no HTML. Isso mantém o dado puro e o estilo controlado.
    • line-height: Define a altura da linha, este é o segredo da leitura confortável. Um valor de 1.5 ou 1.6 é o padrão da indústria para garantir que as linhas não "sangrem" uma sobre a outra, mantendo a escaneabilidade.
  3. A Cor do Texto (color)

    A propriedade color é uma das mais simples e poderosas do CSS. Imagine que você está escrevendo em um papel. A propriedade color é a cor da tinta da sua caneta. Ela não pinta o papel, não pinta a mesa; ela define apenas a cor dos caracteres que formam as palavras.

    Acessibilidade e Contraste

    No desenvolvimento profissional, escolher a cor do texto não é apenas uma questão estética. Existe um conceito chamado Contraste de Cor, que é a diferença de luminosidade entre a cor da letra (color) e a cor que está por trás dela.

    Se o contraste for baixo, você está criando uma barreira técnica para usuários com baixa visão, daltonismo ou até mesmo para alguém tentando ler seu site sob luz solar intensa.

    • Texto Escuro em Fundo Claro: É o padrão de livros e sites de notícias. Cansa menos a vista. Podendo alterar para texto claro em fundo escuro que é muito usado em "Modo Noturno".
    • Hierarquia Visual: Use tons mais escuros para conteúdos principais e tons levemente mais claros (mas ainda dentro do contraste) para informações secundárias. Isso guia o olho do usuário sem sacrificar a leitura.
    • O Erro: Usar um texto cinza claro em um fundo branco. Se o usuário tiver qualquer dificuldade visual ou estiver sob o sol, ele não conseguirá ler nada.
