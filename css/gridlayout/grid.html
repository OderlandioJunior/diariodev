CSS Grid Layout: A Malha Bidimensional Profissional

O CSS Grid é o sistema de layout mais robusto do CSS. Enquanto o Flexbox foca em uma dimensão por vez, o Grid permite controlar linhas e colunas simultaneamente. Ele introduz o conceito de "malha", onde definimos a estrutura do container primeiro e depois posicionamos os elementos nesta grade.

Definindo a Malha (O Container)

Ao aplicar display: grid;, transformamos o elemento em um Grid Container. Utilizamos as propriedades de template para definir as faixas (tracks):

  1. grid-template-columns: Define as colunas.
  2. grid-template-rows: Define as linhas.
  3. Unidade fr: Representa uma fração do espaço livre, lidando com o redimensionamento de forma muito mais inteligente que porcentagens.

No CSS, controlamos a declaração da seguinte maneira:

                    .container {
                        display: grid;

                        grid-template-columns: 200px 1fr 2fr; 
                        /* Coluna fixa + duas flexíveis */

                        gap: 20px;
                        /* Espaçamento entre células */
                    }

Alinhamento e Justificação (O Coração do Grid)

Esta é a parte essencial para o acabamento visual. Podemos alinhar os itens dentro de suas células ou o grid inteiro dentro do container.

  1. Alinhamento de Itens (Dentro da Célula):
    • justify-items: Alinha o conteúdo horizontalmente (eixo da linha).
    • align-items: Alinha o conteúdo verticalmente (eixo da coluna).
    • Valores: start, end, center, stretch.
  2. Alinhamento do Grid (O Container):
    • justify-content e align-content: Posicionam a malha inteira caso ela seja menor que o tamanho do elemento pai.

Atalho (Shorthand):

Utilize place-items: center; para centralizar o conteúdo nos dois eixos com apenas uma linha de código.

Grid Template Areas (O Mapa Visual)

Uma das funcionalidades mais práticas é "desenhar" o layout usando nomes, o que torna o código extremamente fácil de ler e manter.

Exemplo de Mapa de Layout:

                    
                        .container {
                            display: grid;
                            grid-template-areas:
                                "header header header"
                                "sidebar main main"
                                "footer footer footer";
                        }
                        .item-header { grid-area: header; }
                        .item-main { grid-area: main; }

Funções Especiais e Grid Responsivo

Para evitar repetições e criar layouts que se adaptam sem Media Queries, usamos:

  1. repeat(): Simplifica colunas iguais. Ex: repeat(3, 1fr).
  2. minmax(): Garante um tamanho mínimo e permite crescer até um máximo.
  3. auto-fit / auto-fill: Faz o navegador criar colunas automaticamente conforme o espaço disponível.

Código de Grid "Mágico":

                    
                        .grid-auto {
                            display: grid;
                            /* Cria colunas de no mínimo 250px que ocupam o espaço restante */
                            grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
                        }

Grid Implícito e Posicionamento Insectionidual

  • grid-auto-rows: Define o tamanho de linhas criadas automaticamente quando o conteúdo excede o template definido.
  • justify-self / align-self: Permite que um único item quebre a regra do pai e se alinhe sozinho na sua célula.

Boas Práticas e Engenharia

  • Grid vs Flex: Use Grid para o esqueleto principal da página (estruturas 2D) e Flexbox para componentes internos (estruturas 1D, como ícones em um cabeçalho).
  • Subgrid: Para alinhamentos complexos entre pais e filhos, utilize display: subgrid;, permitindo que o filho herde as linhas do pai.
  • Acessibilidade: Sempre mantenha a ordem lógica no HTML. O Grid permite mover itens visualmente, mas o leitor de tela seguirá a ordem das tags.
