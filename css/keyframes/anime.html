Keyframes: A Engenharia de Animações no CSS

A regra @keyframes é utilizada para criar animações complexas, permitindo que um elemento mude gradualmente de um estilo para outro. Diferente das transições simples, que precisam de um gatilho (como o :hover), as animações com keyframes podem ser executadas automaticamente e possuir múltiplas etapas.

Definindo o Roteiro (A Regra @keyframes)

Para criar uma animação, você primeiro define um nome para ela e descreve o que acontece em cada estágio do tempo. O tempo é medido de 0% (início) a 100% (fim).

  • from e to: São atalhos para 0% e 100%.
  • Porcentagens: Permitem criar paradas intermediárias (ex: 25%, 50%, 75%).

Exemplo de Código:

                    
                        @keyframes flutuar {
                            0% { transform: translateY(0); }
                            50% { transform: translateY(-10px); }
                            100% { transform: translateY(0); }
                        }

Aplicando a Animação (A Propriedade animation)

Depois de criar o roteiro, você precisa dizer ao elemento para "atuar". Usamos a propriedade animation, que possui várias subpropriedades:

  1. animation-name: O nome que você deu ao @keyframes.
  2. animation-duration: Quanto tempo a animação leva (ex: 3s).
  3. animation-iteration-count: Quantas vezes ela repete (infinite para um loop eterno).
  4. animation-timing-function: A velocidade da curva (ex: ease-in-out para movimentos suaves).

A Shorthand animation

Para manter o código limpo, costumamos declarar tudo em uma única linha. A ordem geralmente é: nome, duração, curva de tempo e contagem.

Sintaxe da Shorthand:

animation: [name] [duration] [timing-function] [delay] [iteration-count];

Exemplo Prático:

                    
                        .botao-pulsante {
                            /* Nome: flutuar, dura 2s, suave, infinito */
                            animation: flutuar 2s ease-in-out infinite;
                        }

Otimização e Performance

Animações podem pesar no processamento se não forem bem feitas.

  • Propriedades "Baratas": Prefira animar transform (mover, girar, escalar) e opacity. Elas são processadas diretamente pela placa de vídeo (GPU).
  • Propriedades "Caras": Evite animar width, height, margin ou top/left, pois elas forçam o navegador a recalcular o layout de toda a página a cada quadro da animação.

Boas Práticas de Engenharia

  • Acessibilidade: Alguns usuários têm sensibilidade a movimentos (vestibular). Sempre que possível, respeite a media query @media (prefers-reduced-motion: reduce) para desativar animações bruscas.
  • Reutilização: Crie animações genéricas (como um fade-in) no seu arquivo de variáveis ou de base para usá-las em vários elementos diferentes do blog.
  • Modo de Preenchimento (animation-fill-mode): Use forwards se você quiser que o elemento permaneça com o estilo final da animação após ela acabar.
