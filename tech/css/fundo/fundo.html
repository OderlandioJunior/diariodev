Plano de Fundo

Engenharia de Planos de Fundo: Camadas, Comportamento e Performance

O background no CSS não é apenas uma propriedade, mas um conjunto de subpropriedades que definem a camada visual situada atrás do conteúdo. Dominar essas ferramentas permite criar interfaces profundas, responsivas e visualmente ricas sem sacrificar a semântica do HTML.

A Fundação (Color e Image)

Toda estilização de fundo começa pela definição da substância: cor ou textura.

  1. background-color: Preenche o espaço total do elemento (incluindo o padding).
    • Uso Profissional: Sempre defina uma cor de fundo, mesmo ao usar imagens. Isso garante que o texto permaneça legível caso a imagem falhe ou demore a carregar.
    • Exemplo: background-color: #1a1a1a;
  2. background-image: Define um ou mais arquivos de imagem ou gradientes como fundo.
    • Exemplo: background-image: url('assets/textura-dark.jpg');

Controle de Geometria e Proporção

Inserir a imagem é apenas o primeiro passo. O segredo está em como ela se adapta ao tamanho da caixa.

  • background-repeat: Por padrão, o navegador repete a imagem nos eixos X e Y.
    • Valores comuns: no-repeat (exibe apenas uma vez), repeat-x (repete apenas horizontalmente) ou space (gera repetições com espaçamento uniforme).
    • Exemplo: background-repeat: no-repeat;
  • background-size: Define a escala da imagem.
    • cover: A imagem é redimensionada para cobrir todo o elemento. Pode haver cortes, mas nunca espaços vazios.
    • contain: A imagem é exibida inteira, ajustando-se à altura ou largura disponível.
    • Exemplo: background-size: cover;
  • background-position: Define o ponto de origem.
    • Uso Técnico: Útil para garantir que o "assunto" da foto (ex: o rosto de uma pessoa) não seja cortado em telas menores.
    • Exemplo: background-position: center center; (ou use porcentagens como 25% 75%).

Background-attachment (O Controle de Rolagem)

Esta propriedade define o comportamento do fundo em relação ao scroll (rolagem) da página. É aqui que criamos efeitos de profundidade avançados.

  • scroll (Padrão): O fundo está "fixo" ao elemento. Se o elemento sobe, o fundo sobe junto.
  • fixed: O fundo está "fixo" em relação à janela do navegador (viewport). Isso cria o efeito de paralaxe, onde o conteúdo parece deslizar por cima de uma janela aberta para a imagem de fundo.
  • local: O fundo rola junto com o conteúdo interno do elemento. Essencial para áreas de texto longas com scroll próprio.
  • Exemplo: background-attachment: fixed;

Gradientes (Renderização Algorítmica)

Gradientes não são arquivos de imagem, mas cálculos matemáticos feitos pelo navegador. Isso os torna extremamente leves e responsivos.

  • linear-gradient: Transições lineares de cores.
    • Sintaxe: Você define a direção (em graus ou palavras-chave) e as "paradas" de cor.
    • Exemplo: background-image: linear-gradient(to right (ou 135deg), #6e8efb, #a777e3);
  • radial-gradient: Transições que partem de um ponto central (círculo ou elipse).
    • Exemplo: background-image: radial-gradient(circle, #ff00de, #000);

A Propriedade Shorthand (Abreviada)

Para manter o Exemplo limpo (clean code), podemos declarar quase todas as propriedades anteriores em uma única linha. A ordem padrão é importante para evitar bugs de leitura.

Sintaxe da Shorthand:

background: [color] [image] [repeat] [attachment] [position] / [size];

Boas Práticas de Engenharia Frontend

  • Performance: Imagens de fundo (background-image) não são indexadas pelo Google como imagens de conteúdo (<img>). Use o CSS apenas para fins decorativos.
  • Fallback: Sempre forneça um background-color que contraste bem com o seu color. Se a imagem de fundo for escura e o texto branco, e a imagem não carregar, o fundo branco padrão do navegador tornará o texto invisível.
  • Múltiplos Fundos: O CSS permite empilhar fundos. O primeiro da lista fica por cima.
    • background: url('overlay.png'), url('fundo.jpg');

Colocando a mão na massa

Analisar o código "bruto" é fundamental para compreender como a sintaxe se transforma em estrutura e como as boas práticas de indentação e semântica facilitam a manutenção do projeto a longo prazo.

aside {
    background: #000 url('montanha.jpg') no-repeat fixed cover;
}
