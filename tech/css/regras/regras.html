Regras At (@-rules): As Instruções de Comportamento do CSS

Diferente dos seletores comuns, as Regras At são comandos que instruem o navegador sobre como processar o código CSS em diferentes cenários. Elas sempre começam com o símbolo @ seguido por um identificador, e são fundamentais para criar sites responsivos, importar fontes e organizar arquiteturas de código complexas.

Importação e Codificação

Estas regras geralmente ficam no topo do arquivo CSS, pois definem as bases do que será lido a seguir.

  • @charset: Define a codificação de caracteres do arquivo (geralmente UTF-8).
    • Importante: Deve ser a primeira coisa no arquivo, antes de qualquer outro código.
  • @import: Permite importar estilos de outro arquivo CSS.
    • Uso Técnico: Útil para carregar fontes do Google Fonts ou separar o CSS em arquivos menores (ex: header.css, footer.css).

Colocando a mão na massa

Analisar o código "bruto" é fundamental para compreender como a sintaxe se transforma em estrutura e como as boas práticas de indentação e semântica facilitam a manutenção do projeto a longo prazo.

@charset "UTF-8";

@import url('https://...);

Condicionais e Responsividade

Aqui é onde o CSS ganha inteligência para se adaptar ao dispositivo do usuário.

  • @media:A regra mais importante para o Design Responsivo. Ela permite aplicar estilos apenas se certas condições forem atendidas (como a largura da tela).
  • @supports: Verifica se o navegador suporta uma tecnologia específica antes de aplicá-la. É uma "rede de segurança" para usar recursos modernos sem quebrar o site em navegadores antigos.

Colocando a mão na massa

@media (max-width: 600px) {
    body { 
        background-color: ; 
    }
}

@supports (display: grid) {
    main { 
        display: grid; 
    }
}

Fontes e Animações Personalizadas

Estas regras definem recursos que não existem por padrão no navegador e precisam ser "criados" via código.

  • @font-face: Permite que você carregue uma fonte baixada, sem depender de serviços externos.
  • @keyframes: Define as etapas de uma animação CSS. Você cria o "roteiro" do movimento aqui para depois aplicá-lo a um seletor.

Colocando a mão na massa

@font-face {
    font-family: 'NomeDaSuaFonte';
    src: url('fonts/sua-fonte.woff2') format('woff2'),
        url('fonts/sua-fonte.woff') format('woff'),
        url('fonts/sua-fonte.ttf') format('truetype');
    font-weight: 400;
    font-style: normal;
}
body {
    font-family: 'NomeDaSuaFonte', sans-serif;
}

@keyframes aparecer {
    from { 
        opacity: 0;
    }
    to { 
        opacity: 1; 
    }
}

Boas Práticas e Engenharia de Regras

  • Performance do @import: Evite usar muitos @import dentro de arquivos CSS grandes, pois cada um gera uma nova requisição ao servidor, o que pode deixar o site lento. Prefira linkar os arquivos diretamente no HTML quando possível.
  • Ordem das Media Queries: Sempre organize suas @media de forma lógica (ex: do menor para o maior dispositivo, ou vice-versa). Isso evita que uma regra sobrescreva a outra por engano.
  • Escopo: Lembre-se que regras como @keyframes e @font-face são globais; uma vez definidas, podem ser usadas em qualquer lugar do seu projeto.
