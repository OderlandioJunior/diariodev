Seletores Especiais: Estados, Comportamento e Pseudo-elementos

No desenvolvimento moderno, selecionar um elemento pelo nome da tag ou classe é apenas o básico. Para criar interfaces interativas, precisamos de seletores que identifiquem o estado de um elemento (como um botão sendo clicado) ou partes específicas de sua estrutura (como a primeira letra de um parágrafo).

Pseudo-classes de Estado (Interatividade)

Pseudo-classes são palavras-chave adicionadas a um seletor que especificam um estado especial do elemento selecionado. Elas começam sempre com um único dois-pontos (:).

  • :hover: Ativado quando o usuário passa o cursor sobre o elemento. Essencial para indicar que algo é clicável.
  • :focus: Ativado quando o elemento recebe foco (via teclado ou clique). É o pilar da acessibilidade em formulários.
  • :active: Ativado no exato momento do clique, antes de soltar o botão do mouse.
  • :visited: Usado em links para indicar que o usuário já navegou por aquele endereço.

Seletores Estruturais (Lógica de Árvore)

Estes seletores permitem que você estilize elementos com base em sua posição dentro do HTML, evitando a necessidade de criar classes para tudo.

  • :nth-child(valor): Seleciona o "enésimo" filho. Você pode usar como valores: números, ou fórmulas como odd (ímpares) e even (pares).
    • Uso Técnico: Ideal para zebrar tabelas ou listas de itens.
  • :first-child e :last-child: Selecionam, respectivamente, o primeiro e o último filho dentro de um container.
  • :not(seletor): Seleciona todos os elementos, exceto o que estiver dentro dos parênteses. É um seletor de negação poderoso.

Pseudo-elementos (Injeção de Conteúdo e Estilo)

Enquanto pseudo-classes lidam com estados, os pseudo-elementos permitem estilizar partes específicas de um elemento ou inserir conteúdo puramente decorativo via CSS. Usam dois-pontos duplos (::).

  • ::before e ::after: Criam um elemento "fantasma" antes ou depois do conteúdo real.
    • Regra de Ouro: Eles exigem a propriedade content: ""; para serem renderizados.
    • Uso: Inserir ícones, aspas decorativas ou detalhes gráficos sem sujar o HTML.
  • ::placeholder: Estiliza o texto de dica dentro de campos de formulário (inputs).
  • ::selection: Controla a cor do fundo e do texto quando o usuário destaca (seleciona) uma parte do seu site.

Boas Práticas e Engenharia de Seletores

  • Especificidade: Lembre-se que seletores especiais aumentam a especificidade do seu CSS. Se você abusar de :nth-child em estruturas muito profundas, pode ter dificuldade para sobrescrever esses estilos depois.
  • Acessibilidade: Nunca esconda o estado de :focus. Se você remover o estilo de foco, usuários que navegam por teclado não saberão onde estão.
  • Semântica Visual: Use :hover e :active para dar feedback imediato. O usuário nunca deve ter dúvida se o clique dele foi registrado pelo sistema.

Colocando a mão na massa

Analisar o código "bruto" é fundamental para compreender como a sintaxe se transforma em estrutura e como as boas práticas de indentação e semântica facilitam a manutenção do projeto a longo prazo.

a {
    text-decoration: none;
}

a:hover {
    text-decoration: underline;
}

a::after {
    content:"Próximo"
}
